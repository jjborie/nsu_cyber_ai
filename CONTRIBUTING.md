# Contributing

Small, well-explained student contributions are welcome. Discuss larger dependencies or architecture changes in an issue first.

1. Fork the repository and create a focused branch.
2. Read `CLAUDE.md`; implement one feature or fix.
3. Update relevant documentation and checks.
4. Run the build and verification commands in the README. For UI changes, manually check the browser flow and keyboard access.
5. Open a pull request describing the change, why it helps, checks run, and remaining limitations. Review any AI-generated code yourself.

Keep discussion respectful. Use fictional examples, avoid personal data and credentials, and keep generated build output out of contributions.
